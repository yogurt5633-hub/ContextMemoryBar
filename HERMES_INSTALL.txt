ОБНОВЛЕНИЕ CONTEXT MEMORY BAR 1.1.2

Если Context Memory Bar уже установлен, замени существующую папку context-memory-bar содержимым этой версии ЦЕЛИКОМ. Вторую копию рядом не устанавливай. После замены сделай Ctrl+F5 или перезапусти SillyTavern.

Что изменилось:
1. Шкала и счётчики токенов сохранены.
2. Добавлено определение фактического выпадения начала истории через штатную границу SillyTavern lastInContextMessageId.
3. При первом выпадении появляется одно toast-предупреждение.
4. После первого предупреждения оно не повторяется при каждой генерации.
5. Каждая новая Branch имеет собственный одноразовый флаг предупреждения (по chatId конкретной ветки). Если в родительской ветке предел уже достигался, в новой ветке предупреждение снова появится при первом новом выпадении истории.
6. Редактирование промежуточных сообщений не ломает детектор: сравнения текста/постоянных ID сообщений нет.
7. Quiet/background и dry-run генерации игнорируются.
8. Пока последний обычный запрос имеет обрезанную историю, возле общего счётчика показывается ⚠.
9. Для Prompt Manager подсчёт ChatHistory уточнён: conversation + chatHistory.
10. Исправлена мобильная/узкая разметка: при ширине <=1000 px полоса переносится внутрь #sheld, поэтому не исчезает при переключении SillyTavern в mobile layout.

Установка:
1. Найди активную папку пользовательского расширения context-memory-bar (для профиля default-user это обычно внутри data/default-user/extensions; используй фактический путь текущей установки).
2. Замени в ней manifest.json, index.js, style.css и остальные файлы файлами из этого архива.
3. Не меняй исходники SillyTavern.
4. Сделай Ctrl+F5 / перезапусти ST.
5. В консоли должна появиться строка [context-memory-bar] loaded v1.1.2.
6. Сделай обычную генерацию и проверь шкалу.

Расширение не добавляет ничего в промпт и само по себе не расходует токены модели.
