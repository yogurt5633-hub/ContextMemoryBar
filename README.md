# Context Memory Bar — SillyTavern

Минимальное визуальное расширение для SillyTavern. Оно не изменяет промпт и не добавляет в него токены. Внизу окна показывает расход контекста последней генерации и предупреждает, когда начало обычной истории чата уже перестало помещаться в контекст модели.

## Шкала

1. **Фиолетовый `#8B5CF6`** — Main Prompt + Scenario + World Info + Author's Note + Summary + примеры + служебные инструкции + всё остальное, кроме двух категорий ниже.
2. **Оранжевый `#F59E0B`** — Character Description + Character Personality + Persona Description.
3. **Синий `#3B82F6`** — ChatHistory.
4. **Зелёный `#16A34A`** — оставшееся место полного контекстного окна.

В каждом сегменте показывается число токенов. Справа поверх полосы: `занято / полный размер контекста`, например `23 200 / 40 000`.

Знаменатель — именно **полный настроенный размер контекста**, без вычитания Max Response Tokens.

## Выпадение истории

Расширение больше не пытается определять выпадение старых сообщений только по числу свободных токенов. После сборки реального запроса оно читает штатную границу истории SillyTavern `lastInContextMessageId`.

Если SillyTavern уже вынужден отбросить начало обычной истории чата, расширение:

- один раз показывает toast: **«Начало истории больше не помещается в контекст. Первые сообщения больше не передаются модели как часть обычной истории.»**;
- добавляет значок `⚠` перед счётчиком `занято / контекст`, пока последний обычный запрос действительно имеет обрезанную историю;
- не повторяет toast при каждой следующей генерации;
- не зависит от текста сообщений и поэтому нормально переживает редактирование старых/промежуточных сообщений;
- игнорирует quiet/background и dry-run генерации, чтобы служебные запросы расширений не создавали ложное предупреждение.

### Ветки

Начиная с **1.1.1**, флаг «предупреждение уже было» хранится **отдельно для каждой конкретной ветки/файла чата**. Основным ключом служит `chatId` конкретного файла/ветки. Это надёжнее для веток: в некоторых версиях SillyTavern дочерняя Branch могла наследовать `integrity` родителя. `integrity` используется только как запасной вариант, если `chatId` недоступен.

Поэтому сценарий:

`основной чат → достигнут предел → Branch #1 → удалить старые сообщения → снова достигнут предел`

даст **новое одноразовое предупреждение в Branch #1**. При редактировании или удалении сообщений внутри уже существующей ветки её флаг не сбрасывается, поэтому повторных toast при каждой генерации не будет. Следующая новая Branch снова начинает с чистого состояния предупреждения.

Состояние хранится в `extensionSettings` SillyTavern и сохраняется на сервере для текущего пользовательского профиля. Если этот API недоступен, предусмотрен локальный fallback через `localStorage`.

## Адаптация интерфейса

Начиная с **1.1.2**, расширение повторяет точку переключения мобильной разметки SillyTavern — `1000px`.

- при ширине **больше 1000px** полоса остаётся `position: fixed` на нижней границе окна, как раньше;
- при ширине **1000px и меньше** полоса переносится внутрь `#sheld` и становится отдельной нижней строкой flex-разметки;
- при обратном расширении окна полоса автоматически возвращается в `body`;
- это устраняет исчезновение полосы в диапазоне, где SillyTavern уже включил мобильный интерфейс, а старая версия расширения ещё использовала desktop-позиционирование.

Сама логика подсчёта токенов и одноразовых предупреждений 1.1.1 не изменена.

## Откуда берутся токены

Для Chat Completion / OpenRouter во время генерации расширение берёт счётчики из Prompt Manager SillyTavern. История учитывает обе штатные коллекции `conversation + chatHistory`.

После завершения данные привязываются к последнему Prompt Itemization и сохраняются локально для этого чата. Для старых сообщений и Text Completion используется сохранённый Prompt Itemization SillyTavern.

Первая (фиолетовая) категория вычисляется как остаток от общего занятого объёма, поэтому четыре части шкалы остаются согласованы между собой.

## Установка / обновление

Если уже установлена 1.0.x, **не ставь вторую копию**. Замени содержимое существующей папки `context-memory-bar` содержимым этой версии и сделай полную перезагрузку страницы SillyTavern (`Ctrl+F5`).

Для установки с нуля папку `context-memory-bar` нужно поместить в пользовательские UI-расширения активного пользователя SillyTavern (`data/<user-handle>/extensions/...`, конкретную вложенность можно определить по уже установленным third-party расширениям).

После установки сделай обычную генерацию. В консоли браузера должна появиться строка:

`[context-memory-bar] loaded v1.1.2`

## Файлы

- `manifest.json` — манифест расширения;
- `index.js` — расчёт шкалы, отслеживание реальной границы истории и разовое предупреждение;
- `style.css` — внешний вид;
- `HERMES_INSTALL.txt` — короткая инструкция для установки через Hermes/вручную.
